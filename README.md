# The Four Tempers - MI-349 Lab 2

A single page HTML5 site built for lab 2. It is a ficitonal internal employee wellness page covering the Four Tempers. Inspired by Lumon Industries from the AppleTV series Severance. 

## The Purpose of This Page

This page is meant to act as an informative resource for Lumon employees, and provides a quick overview of the tempers and what they mean. In addition, the page provides a brief description for each temper.
