# The Four Tempers - MI-349 Lab 2

A single page HTML5 site built for 3.6 Lab: Hello World. It is a ficitonal internal employee wellness page covering the Four Tempers. Inspired by Lumon Industries from the AppleTV series Severance. 

## The Purpose of This Page

This page is meant to act as an informative resource for Lumon employees, and provides a quick overview of the tempers and what they mean. In addition, the page provides a brief description for each temper. 

## Structure and Elements Used

The webpage incorporates a header and footer, an unordered list, several section headings, dividing lines, an image, and the sections themselves. In addition, the head includes metadata providing a description for the website as well as a theme color.
